# Fruit Classification Analysis

## 📊 Project Overview
This is a class project focused on exploratory data analysis of a fruit dataset. The goal is to analyze fruit characteristic of different types of fruits.

## 🎯 Objectives
- Perform exploratory data analysis (EDA) on the fruit dataset
- Visualize key features and patterns in the data

## 🛠️ Technologies Used
- **Python 3.x**
- **pandas** - Data manipulation and analysis
- **numpy** - Numerical computing
- **matplotlib** - Data visualization

## 📁 The project Structure
```
data_analysis/
│
├── data/                  # Dataset files
├── notebooks/             # Jupyter notebooks
├── requirements.txt       # Python dependencies
└── README.md             # Project documentation
```

## 🚀 Installation

1. Clone the repository
```bash
git clone https://github.com/alixHub-ux/data_analysis.git
cd data_analysis
```

2. Create a virtual environment
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

3. Install dependencies
```bash
pip install -r requirements.txt
```

## 📈 Usage

Explore the Jupyter notebooks:
```bash
jupyter notebook
```

## 📊 Dataset
The dataset contains various features of fruits including:
- Physical characteristics (size, weight, color)
- Texture properties
- Nutritional information
- Fruit type labels

## 🔍 Analysis Steps
1. Data loading and preprocessing
2. Exploratory data analysis
3. Feature engineering
4. Model training and evaluation
5. Results interpretation
